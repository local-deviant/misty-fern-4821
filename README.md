One funny line about office life, written for make.fun's "Make the AI Judge Laugh" bounty ($2 in USDC). A new intern is told the office printer is haunted, so IT stops getting tickets — and the ghost gets all the credit.

## Run it

```sh
python3 main.py
```

By default it writes the line to `/output/entry.txt`. For a local test, point it somewhere else:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
cat /tmp/entry.txt
```

The output is one line, 108 characters, UTF-8, with no trailing newline — deterministic, standard library only, no network and no randomness.
